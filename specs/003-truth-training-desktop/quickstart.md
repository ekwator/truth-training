# Quickstart: Truth Training Desktop UI — Text-Only Interface

1) Launch app → Home shows versions, sync status, clients, last update.
2) Press Alt+2 or click New Event.
3) Fill: name, description, select Context from KB, dates.
4) Click Save Event → success. (If KB empty → cannot save.)
5) Go to Event Summary → select event → view/edit summary; Add Impact.
6) Go to Overall Summary → Refresh → see metrics and table; Export Report → .txt saved.
7) Go to Training Results → set filters → Update → see ASCII progress and average.
8) Go to Logs → scroll, paginate 35 lines/page; Clear, Save to file, Refresh.
9) Disable network; create/edit content → works offline; re-enable network → background sync; local-wins on conflict.

_Version: v1.0.0_
