# Contracts для ATPP

В этом каталоге описаны контрактные требования для всех ключевых flows ATPP:
- event_creation.yaml: создание события
- relay_event.yaml: ретрансляция события
- observe_etf.yaml: отображение и наблюдение ETF
- ttl_expiry.yaml: проверка истечения TTL
- rate_limit_violation.yaml: поведение при превышении лимита публикаций

Каждый файл описывает: входные параметры, выход, логику проверки и допустимые ошибки для соответствующего endpoint/flow.
Контракты нужны для тестов, валидации реализации и коммуникации между компонентами/узлами сети.
