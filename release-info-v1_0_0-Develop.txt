Truth Training v1.0.0-Develop — Development Release for Learning and Practice

This development release builds upon v1.0.0-Release with enhanced localization support, improved documentation, and refined CI/CD workflows. This version is specifically designed for developers learning to use Cursor AI IDE and modern cross-platform development practices.

Highlights
- Desktop UI Localization:
  - Full Russian (RU) and English (EN) language support with dynamic switching
  - Locale-aware knowledge base seeding (Core supports `seed_knowledge_base` with locale parameter)
  - Automatic knowledge base reseeding when locale changes via `reseed_knowledge_base` Tauri command
  - Complete translation coverage for all UI strings (navigation, dashboard, events, settings, errors)
  - Locale persistence in `~/.truth-training/config.json`
  - Fallback to English with telemetry events for missing translations
- Documentation Enhancements:
  - Comprehensive logging documentation (`docs/logging.md`) covering all platforms
  - Updated functional specifications (22-function_core.md, 23-function_desktop.md, 24-function_mobile_android.md) with localization details
  - CLI tool documentation and workflow (`cli-build.yml`) for `truthctl` binary builds
  - Expanded artifact documentation in `docs/Truth-training/Truth-training.md`
- CI/CD Improvements:
  - Fixed Tauri CLI installation method (npm instead of cargo) to resolve flate2 compilation errors
  - Corrected CLI build workflow to target `app` package for `truthctl` binary
  - Workflow optimizations to prevent unnecessary runs on main branch pushes
  - Cross-platform artifact generation and publishing

Known Limitations & Future Work
- Android Client:
  - **Localization**: English-only (EN) - Russian localization not implemented
  - **Screen Coverage**: Not all activities/screens are fully implemented compared to Desktop UI
  - **Missing Features**: Some advanced features from Desktop UI need Android equivalents
  - **Recommendation**: Implement full screen coverage matching Desktop UI's 8 screens, add Russian translations (`values-ru/strings.xml`), and integrate locale-aware knowledge base seeding
- iOS Client:
  - **Status**: Basic project structure exists, but full implementation is required
  - **Missing**: Complete UI implementation, feature parity with Desktop/Android
  - **Recommendation**: Full iOS client development needed to match Desktop UI functionality
- CLI Tool (`truthctl`):
  - **Status**: Core functionality implemented (node management, sync, discovery)
  - **Limitation**: Direct CLI commands for events and context templates are planned for future releases
  - **Current Workaround**: Use HTTP API endpoints (`/api/v1/events`, `/api/v1/contexts`) or Desktop UI

Platform Comparison
- **Desktop UI**: Most complete implementation with full localization (RU/EN), all 8 screens, comprehensive testing, and production-ready features
- **Android Client**: Partial implementation with EN-only localization, basic screens, and core API coverage
- **iOS Client**: Project structure only, requires full implementation
- **Core Library**: Full feature support with locale-aware knowledge base seeding
- **CLI Tool**: Functional for node management and sync, with planned enhancements for event/context management

Quality & Validation
- Updated functional specifications reflect current localization implementation
- Documentation integrity maintained with comprehensive logging guides
- CI/CD workflows validated and optimized
- Cross-platform compatibility verified

For Beginner Developers

This release is created for beginner developers to practice using Cursor AI IDE. When studying this project with Cursor AI IDE, you can receive hints and guidance on both implementing this project and independently developing additional features. You can learn the technologies and programming languages used in the project, and Cursor AI IDE can autonomously make changes to the project.

Technologies and Programming Languages Used:
- **Backend Core**: Rust (stable toolchain), Actix-web (HTTP server), Tokio (async runtime), rusqlite (SQLite), ed25519-dalek (cryptography), serde (serialization), clap (CLI parsing)
- **Desktop UI Frontend**: TypeScript, JavaScript, React 18, Vite (build tool), Zustand (state management), Axios (HTTP client), Tailwind CSS (styling), Headless UI (components)
- **Desktop UI Backend**: Tauri 2.9.0 (desktop framework), Rust (Tauri commands), SQLite via rusqlite
- **Android Client**: Kotlin 2.0.20, Android SDK (API 24+, target 35), Jetpack Compose (UI), Room (database), Retrofit (networking), OkHttp (HTTP client), WorkManager (background tasks), Kotlin Coroutines (async), BouncyCastle (cryptography), Gradle (build system)
- **iOS Client**: Swift (planned), SwiftUI (planned), Rust FFI bindings
- **Testing**: Jest (JavaScript), React Testing Library, Playwright (E2E), JUnit (Java/Kotlin), Android Instrumentation Tests
- **Build Tools**: Cargo (Rust), npm/pnpm (Node.js), Gradle (Android), Xcode (iOS)
- **CI/CD**: GitHub Actions, Python 3.11 (documentation tools)
- **Documentation**: Markdown, Python scripts for doc-refactor automation
- **Database**: SQLite 3.x (shared across all platforms)
- **Cryptography**: Ed25519 signatures, ChaCha20-Poly1305 encryption

Cursor AI IDE can help you:
- Understand code structure and architecture
- Generate code following project patterns
- Refactor and improve existing code
- Write tests and documentation
- Debug and fix issues
- Learn best practices for each technology stack
- Implement new features following project conventions
