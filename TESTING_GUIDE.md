# Руководство по тестированию на физическом устройстве

## Установка и запуск

### Шаг 1: Подключение устройства
```bash
# Проверить подключение
adb devices

# Должен показать ваше устройство (например: 1813294310FA0RPT	device)
```

### Шаг 2: Сборка APK
```bash
cd truth-android-client
./gradlew assembleLocalDebug
```

### Шаг 3: Установка на устройство
```bash
# Из корня проекта
adb install -r truth-android-client/app/build/outputs/apk/local/debug/app-local-debug.apk

# Или полный путь
adb install -r /home/ekwator/Code/truth-training/truth-android-client/app/build/outputs/apk/local/debug/app-local-debug.apk
```

### Шаг 4: Запуск приложения
```bash
adb shell am start -n com.truth.training.client/.MainActivity
```

## Тестирование реализованных функций

### 1. Тестирование "Viewing Network Nodes" (019-android-node-details)

**Шаги:**
1. Откройте приложение
2. Перейдите на вкладку **"Nodes"** в нижней навигации
3. Проверьте отображение списка узлов:
   - ✅ Адреса узлов отображаются
   - ✅ Типы узлов показываются как **"Hub"** или **"Leaf"** (вместо технических типов)
   - ✅ Статус доступности (Reachable/Unreachable) отображается
   - ✅ Эмодзи присутствуют в UI элементах

4. **Клик по карточке узла:**
   - ✅ Тапните на любую карточку узла
   - ✅ Должен открыться экран деталей узла (`NodeDetailScreen`)
   - ✅ Проверьте отображение всех полей:
     - Адрес узла
     - Тип (Hub/Leaf и технический тип)
     - Статус (Reachable/Unreachable)
     - Last Seen (временная метка)
     - TTL
     - Expires In (с подсветкой, если истек)
     - Age
     - Source (или "N/A" если null)
     - Node ID (или "N/A" если null)
     - Created At
     - Updated At
   - ✅ Все UI элементы содержат эмодзи
   - ✅ Все строки локализованы (EN/RU)

5. **Кнопка Refresh:**
   - ✅ Тапните на кнопку обновления в TopAppBar
   - ✅ Данные узла должны обновиться

6. **Навигация назад:**
   - ✅ Тапните на кнопку "Назад" в TopAppBar
   - ✅ Должен вернуться к списку узлов

**Ожидаемые результаты:**
- ✅ Навигация работает корректно
- ✅ Все данные отображаются правильно
- ✅ Эмодзи присутствуют во всех UI элементах
- ✅ Локализация работает (переключение языка в Settings)

### 2. Тестирование "Adding Impacts" (018-android-impacts-judgments)

**Шаги:**
1. Откройте приложение
2. Перейдите на вкладку **"Events"** в нижней навигации
3. Создайте новое событие или выберите существующее:
   - Тапните на событие в списке
   - Откроется экран деталей события (`EventDetailScreen`)

4. **Добавление влияния:**
   - ✅ Найдите кнопку **"Add Impact"** (с эмодзи)
   - ✅ Тапните на кнопку
   - ✅ Должен открыться диалог `AddImpactDialog`
   - ✅ Проверьте элементы диалога:
     - Заголовок с эмодзи
     - Слайдер уровня влияния (1-5)
     - Отображение текущего уровня (например, "Level 3")
     - Поле для заметок (опционально)
     - Кнопки "Save Impact" и "Cancel" (с эмодзи)

5. **Тестирование слайдера:**
   - ✅ Переместите слайдер на уровень 1-3
   - ✅ Проверьте, что кнопка "Save" активна
   - ✅ Переместите слайдер на уровень 4-5
   - ✅ Проверьте, что кнопка "Save" активна

6. **Сохранение влияния:**
   - ✅ Установите уровень влияния (например, 4)
   - ✅ Добавьте заметки (опционально)
   - ✅ Тапните "Save Impact"
   - ✅ Диалог должен закрыться
   - ✅ Влияние должно появиться в списке "Impacts" на экране деталей события
   - ✅ Проверьте отображение:
     - Для уровней 4-5: "Positive (Level 4-5)" (зеленый цвет)
     - Для уровней 1-3: "Negative (Level 1-3)" (красный цвет)
     - Заметки (если добавлены)
     - Временная метка создания

7. **Тестирование пустого состояния:**
   - ✅ Если нет влияний, должно отображаться "No impacts yet"

8. **Тестирование нескольких влияний:**
   - ✅ Добавьте несколько влияний с разными уровнями
   - ✅ Проверьте, что все они отображаются в списке
   - ✅ Список должен обновляться автоматически

**Ожидаемые результаты:**
- ✅ Диалог открывается и закрывается корректно
- ✅ Слайдер работает правильно (1-5)
- ✅ Влияния сохраняются и отображаются
- ✅ Маппинг уровней работает (1-3 → Negative, 4-5 → Positive)
- ✅ Эмодзи присутствуют во всех элементах
- ✅ Локализация работает

### 3. Тестирование "Submitting Judgments" (018-android-impacts-judgments)

**Шаги:**
1. Откройте приложение
2. Перейдите на вкладку **"Events"** в нижней навигации
3. Выберите событие из списка

4. **Отправка суждения:**
   - ✅ Найдите кнопку **"Submit Judgment"** (с эмодзи)
   - ✅ Тапните на кнопку
   - ✅ Должен открыться диалог `SubmitJudgmentDialog`
   - ✅ Проверьте элементы диалога:
     - Заголовок с эмодзи
     - Выбор оценки: "True", "False", "Uncertain" (FilterChips)
     - Слайдер уровня уверенности (0.0-1.0)
     - Отображение процента уверенности (например, "80% confidence")
     - Поле для обоснования (опционально)
     - Кнопки "Submit" и "Cancel" (с эмодзи)

5. **Тестирование выбора оценки:**
   - ✅ Тапните на "True" - должен быть выбран
   - ✅ Тапните на "False" - должен быть выбран
   - ✅ Тапните на "Uncertain" - должен быть выбран

6. **Тестирование слайдера уверенности:**
   - ✅ Переместите слайдер на 0.0
   - ✅ Проверьте отображение "0% confidence"
   - ✅ Переместите слайдер на 1.0
   - ✅ Проверьте отображение "100% confidence"
   - ✅ Переместите слайдер на 0.5
   - ✅ Проверьте отображение "50% confidence"

7. **Отправка суждения:**
   - ✅ Выберите оценку (например, "True")
   - ✅ Установите уровень уверенности (например, 0.8)
   - ✅ Добавьте обоснование (опционально)
   - ✅ Тапните "Submit"
   - ✅ Диалог должен закрыться
   - ✅ Суждение должно появиться в списке "Judgments" на экране деталей события
   - ✅ Проверьте отображение:
     - Оценка (True/False/Uncertain) с соответствующим цветом
     - Процент уверенности
     - Обоснование (если добавлено)
     - Временная метка отправки

8. **Тестирование пустого состояния:**
   - ✅ Если нет суждений, должно отображаться "No judgments yet"

9. **Тестирование нескольких суждений:**
   - ✅ Отправьте несколько суждений с разными оценками
   - ✅ Проверьте, что все они отображаются в списке
   - ✅ Список должен обновляться автоматически

**Ожидаемые результаты:**
- ✅ Диалог открывается и закрывается корректно
- ✅ Выбор оценки работает (FilterChips)
- ✅ Слайдер уверенности работает правильно (0.0-1.0)
- ✅ Суждения сохраняются и отображаются
- ✅ Эмодзи присутствуют во всех элементах
- ✅ Локализация работает

## Известные предупреждения

При сборке могут появиться предупреждения о deprecated `Divider`:
```
'Divider(...)' is deprecated. Renamed to HorizontalDivider
```

Это не критично для тестирования, но можно исправить позже, заменив `Divider` на `HorizontalDivider` в `NodeDetailScreen.kt`.
