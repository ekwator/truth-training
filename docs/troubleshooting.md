# Troubleshooting Guide

This document provides solutions to common compilation and build issues encountered when working with the Truth Training platform.

## 🚨 Critical Issues

### Icon Files Missing ⚠️ **MOST COMMON ISSUE**

**Why icon files aren't in the project by default:**
- Icon files are **generated during CI/CD** to avoid committing large binary files
- Different platforms require different icon formats (PNG, ICO, etc.)
- Icons are created dynamically using ImageMagick in the build process

**Errors you'll see:**
```
failed to open icon .../icons/32x32.png: No such file or directory
icon .../icons/icon.png is not RGBA
couldn't find a square icon to use as AppImage icon
icons/icon.ico not found; required for generating a Windows Resource file
```

**Solution for local development:**
```bash
# 1. Create icons directory
mkdir -p ui/desktop/src-tauri/icons

# 2. Install ImageMagick
sudo apt-get install -y imagemagick

# 3. Create placeholder icons (replace with your actual icons)
# Create 32x32 RGBA PNG
convert -size 32x32 xc:transparent ui/desktop/src-tauri/icons/icon.png

# Create 512x512 RGBA PNG  
convert -size 512x512 xc:transparent ui/desktop/src-tauri/icons/icon-512.png

# Create ICO for Windows
convert ui/desktop/src-tauri/icons/icon.png -resize 256x256 ui/desktop/src-tauri/icons/icon.ico
```

**Icon Requirements:**
- **Linux**: `icon.png` (32x32) + `icon-512.png` (512x512) for AppImage
- **Windows**: `icon.ico` (256x256) for MSI/NSIS installers  
- **macOS**: `icon.png` (32x32) + `icon-512.png` (512x512) for DMG
- **Format**: All must be RGBA PNG (not RGB) for transparency support

## Desktop UI (Tauri) Issues

### 1. Missing Tauri CLI
**Error**: `error: no such command: tauri`
**Solution**:
```bash
cargo install tauri-cli
```

### 2. Missing System Dependencies (Linux)
**Error**: `The system library glib-2.0 required by crate glib-sys was not found`
**Solution**:
```bash
sudo apt-get update
sudo apt-get install -y libgtk-3-dev libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf
```

### 3. Missing Windows Cross-Compilation Tools
**Error**: `Error calling dlltool 'x86_64-w64-mingw32-dlltool': No such file or directory`
**Solution**:
```bash
sudo apt-get install -y gcc-mingw-w64-x86-64
export CC_x86_64_pc_windows_gnu=x86_64-w64-mingw32-gcc
export CXX_x86_64_pc_windows_gnu=x86_64-w64-mingw32-g++
export AR_x86_64_pc_windows_gnu=x86_64-w64-mingw32-ar
export CARGO_TARGET_X86_64_PC_WINDOWS_GNU_LINKER=x86_64-w64-mingw32-gcc
```

### 4. Missing NSIS for Windows Installer
**Error**: `failed to run command makensis.exe: No such file or directory`
**Solution**:
```bash
sudo apt-get install -y nsis
export MAKENSIS_PATH=/usr/bin/makensis
```

### 5. Tauri Configuration Issues
**Error**: `"identifier" is a required property`
**Error**: `Additional properties are not allowed ('devPath', 'distDir')`
**Solution**: Update `tauri.conf.json` to Tauri v2 format:
```json
{
  "$schema": "https://schema.tauri.app/config/2.0.0",
  "productName": "Truth Training",
  "version": "0.1.0",
  "identifier": "com.truth-training.desktop",
  "build": {
    "beforeDevCommand": "npm run dev",
    "beforeBuildCommand": "npm run build",
    "devUrl": "http://localhost:1420",
    "frontendDist": "../dist"
  }
}
```

### 6. Node.js Dependencies Issues
**Error**: `Could not read package.json`
**Solution**: Run commands from correct directory:
```bash
cd ui/desktop
npm install
npm run build
```

**About `node_modules`**:
- Contains all JavaScript/TypeScript dependencies (~676 packages)
- Generated by `npm install` from `package.json` and `package-lock.json`
- Listed in `.gitignore` - never commit to version control
- Safe to delete: `rm -rf node_modules && npm install` recreates it
- Large size due to dependency tree (hundreds of MB)

## Android Build Issues

### 1. Missing Android NDK
**Error**: `failed to find tool "aarch64-linux-android29-clang": No such file or directory`
**Solution**:
```bash
# Install Android NDK
export ANDROID_NDK_HOME=/path/to/android-ndk
export PATH=$PATH:$ANDROID_NDK_HOME/toolchains/llvm/prebuilt/linux-x86_64/bin

# Add Rust targets
rustup target add aarch64-linux-android
rustup target add x86_64-linux-android
```

### 2. APK Output Path Issues
**Issue**: APK files created in subdirectories (`mock/`, `local/`, `remote/`) instead of `debug/` and `release/`
**Solution**: Check correct output paths:
```bash
# APK files are located at:
truth-android-client/app/build/outputs/apk/mock/debug/
truth-android-client/app/build/outputs/apk/local/debug/
truth-android-client/app/build/outputs/apk/remote/debug/
```

## iOS Build Issues

### 1. Missing iOS Targets
**Error**: `Target aarch64-apple-ios is not installed`
**Solution**:
```bash
rustup target add aarch64-apple-ios
rustup target add aarch64-apple-ios-sim
```

### 2. Xcode Not Found
**Error**: `xcodebuild: command not found`
**Solution**:
```bash
# Install Xcode Command Line Tools
xcode-select --install
```

## Cross-Compilation Issues

### 1. Missing Rust Targets
**Error**: `Target x86_64-pc-windows-gnu is not installed`
**Solution**:
```bash
rustup target add x86_64-unknown-linux-gnu
rustup target add x86_64-pc-windows-gnu
rustup target add x86_64-apple-darwin
```

### 2. Feature Compilation Errors
**Error**: `package truth-ui-desktop depends on tauri with feature shell-open but tauri does not have that feature`
**Solution**: Update `Cargo.toml` to remove non-existent features:
```toml
[dependencies]
tauri = { version = "2.5.1", features = [] }

[build-dependencies]
tauri-build = { version = "2.5.1", features = [] }
```

## CI/CD Workflow Issues

### 1. GitHub Actions Artifact Warnings ⚠️ **EXPECTED BEHAVIOR**

**Warning**: `Unable to download artifact(s): Artifact not found for name: libtruth_core-android/ios`

**Why this happens:**
- Workflows try to reuse pre-built Rust libraries from `Cross-Platform Build` workflow
- On direct runs (push/pull_request), these artifacts don't exist yet
- Workflows automatically build from source when artifacts are missing
- This warning is **harmless** and doesn't affect build success

**This is expected and safe to ignore:**
- Workflow logic: `if: ${{ github.event_name == 'workflow_run' }}` + `continue-on-error: true`
- Direct runs build libraries from source (slower but works)
- Dependent runs use artifacts when available (faster)

**No action needed** - the warning appears in logs but builds complete successfully.

## Build Artifact Issues

### 1. Wrong Output Paths
**Issue**: Artifacts not found in expected locations
**Solution**: Check correct paths:
- **Desktop**: `target/{target}/release/bundle/` (not `ui/desktop/src-tauri/target/`)
- **Android**: `truth-android-client/app/build/outputs/apk/{flavor}/debug/`
- **iOS**: `truth-ios-client/build/Products/Release-{platform}/`

### 2. Missing Bundle Files
**Issue**: No files found in bundle directories
**Solution**: Ensure Tauri bundle creation is enabled in `tauri.conf.json`:
```json
{
  "bundle": {
    "active": true,
    "targets": "all"
  }
}
```

## Quick Fix Commands

### Complete Desktop Setup
```bash
# Install all dependencies
sudo apt-get update
sudo apt-get install -y libgtk-3-dev libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf gcc-mingw-w64-x86-64 nsis imagemagick

# Install Rust tools
cargo install tauri-cli
rustup target add x86_64-unknown-linux-gnu
rustup target add x86_64-pc-windows-gnu

# Setup desktop project
cd ui/desktop
npm install

# Create icons (if missing)
mkdir -p src-tauri/icons
convert -size 32x32 xc:transparent src-tauri/icons/icon.png
convert -size 512x512 xc:transparent src-tauri/icons/icon-512.png
convert src-tauri/icons/icon.png -resize 256x256 src-tauri/icons/icon.ico

# Build
npm run build
cargo tauri build
```

### Complete Android Setup
```bash
# Install Android NDK and setup environment
export ANDROID_NDK_HOME=/path/to/android-ndk
export PATH=$PATH:$ANDROID_NDK_HOME/toolchains/llvm/prebuilt/linux-x86_64/bin

# Add Rust targets
rustup target add aarch64-linux-android
rustup target add x86_64-linux-android

# Build
cargo build --release --target aarch64-linux-android --features mobile --lib -p truth_core
cargo build --release --target x86_64-linux-android --features mobile --lib -p truth_core
```

### Complete iOS Setup
```bash
# Add Rust targets
rustup target add aarch64-apple-ios
rustup target add aarch64-apple-ios-sim

# Install Xcode tools
xcode-select --install

# Build
cargo build --release --target aarch64-apple-ios --features mobile --lib -p truth_core
cargo build --release --target aarch64-apple-ios-sim --features mobile --lib -p truth_core
```

## Still Having Issues?

1. **Check the CI/CD logs** in `.github/workflows/` for working examples
2. **Verify all dependencies** are installed correctly
3. **Ensure you're in the correct directory** when running commands
4. **Check file permissions** for generated files
5. **Clear build caches** if needed: `cargo clean`, `rm -rf node_modules`

For additional help, check the main build instructions in [docs/build_instructions.md](build_instructions.md) and [spec/19-build-instructions.md](../spec/19-build-instructions.md).
